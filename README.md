# Accord Manual

Нативный офлайн-справочник для Honda Accord VII: CL7, CL9, CM1, CM2, CN1 и CN2, 2003–2008. Приложение написано на Swift 6 / SwiftUI / SwiftData: оно не использует WebView, сеть или сторонние SDK для чтения руководства.

## Открытие и запуск

Откройте `AccordManual.xcodeproj` в Xcode 16+ и выберите любой iOS 17+ симулятор или подключённое устройство. Цели приложения настроены для iPhone и iPad. Репозиторий содержит встроенный демонстрационный пакет, поэтому проект собирается и запускается без загрузок, локальных путей и исходного Honda ESM. Полный офлайн-пакет руководства не хранится в обычном Git: он содержит большой SQLite-файл и оригинальные изображения.

## Импорт полного руководства

Единственный входной источник для полного пакета — локальная папка Honda ESM. Импортёр не предполагает жёсткой структуры: рекурсивно обнаруживает HTML/HTM, ресурсы, XML-справочники, JS-навигацию и локальные ссылки.

```sh
cd Importer
swift run -c release accord-manual-import \
  --input "/path/to/Honda ESM" \
  --output "../Resources/ManualBundle"
```

Параметр `--no-media` пересоздаёт базу и отчёты без копирования медиа, что удобно для CI и повторного индексирования. Без него импортёр очищает `media/` и копирует только оригинальные изображения, на которые ссылаются статьи, не разрешая выход за каталог источника.

Состав пакета:

- `manual.sqlite` — неизменяемые разделы, лениво читаемые JSON-записи статей, применимость и локальный FTS5-индекс.
- `metadata.json` — версия формата и статистика.
- `diagnostics.json` — неразобранные страницы, отсутствующие медиа и битые локальные ссылки.
- `media/` — исходные локальные изображения, загружаемые лениво.

Пользовательские сущности (`Bookmark`, `UserNote`, `ReadingHistoryEntry`, `ChecklistState`, `VehicleProfile`, `AppSettings`) живут отдельно в SwiftData и никогда не попадают в заменяемый пакет руководства.

## Архитектура

| Путь | Назначение |
| --- | --- |
| `Importer/` | SwiftPM macOS CLI и тесты: HTML/XML-парсинг, нормализация путей, поиск, диагностика. |
| `App/` | Точка входа, SwiftData-контейнер и глобальные зависимости. |
| `Data/ManualStore/` | Codable-модели, чтение SQLite, ленивое фоновое декодирование статей и FTS5-поиск. |
| `Data/UserStore/` | Только пользовательские SwiftData-модели. |
| `Features/` | Нативные экраны руководства, поиска, сохранённого и настроек. |
| `Shared/` | Рендеринг блоков, чек-листы, нативная галерея/zoom. |
| `Resources/ManualBundle/` | Встроенный демонстрационный JSON и локальное место для результатов полного импорта. Большой SQLite-пакет и медиа исключены из Git из-за лимита GitHub на размер файлов. |
| `Tests/` | XCTest и XCUITest сценарии для Xcode. |

Рендерер отображает не сырой HTML, а `heading`, `paragraph`, `numberedSteps`, `bulletList`, `warning`, `note`, `table`, `image`, `link`, `anchor` и `specification`. Предупреждения имеют текстовые подписи, а не полагаются только на цвет. Типографика системная, с поддержкой Dynamic Type; у интерактивных элементов есть осмысленные accessibility labels.

## Проверки

```sh
cd Importer
swift test
swift build -c release
```

В полном Xcode дополнительно выполните:

```sh
xcodebuild -project AccordManual.xcodeproj -scheme AccordManual \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

Unit-тесты покрывают нормализацию ссылок, JavaScript-переходы и якоря, русские/технические токены, дерево разделов, вложенные HTML-блоки, исходные изображения, контекстные заголовки и SQLite FTS. UI-тест проверяет полнотекстовый поиск и открытие реальной статьи.

## Фактическая структура источника и импорт (13 августа 2026)

Источник занимает 633 МБ и содержит 60 817 файлов:

- 22 562 HTML-страницы и 15 535 JS-файлов;
- 22 697 PNG (включая 13 280 с расширением `.PNG` и 9 417 с `.png`), 3 CSS-файла;
- XML в `ru/info/`: `contents_list.xml`, `sct_sc_name_list.xml`, `sys_name_list.xml`, `model_list.xml`, `project.xml` и дополнительные словари;
- frameset-оболочки и JS-деревья `SML_*`, `SMT_*`, `BRL_*`, `BRT_*` для сервисного и кузовного руководств;
- `.DB` миниатюр в `ru/img/` — это кэши, не используемые приложением.

`project.xml` обозначает документ как `ACCORD`, русскую локализацию и дату конвертации 2008‑03‑27. Финальный прогон создаёт SQLite-пакет и каталог из 12 825 используемых оригинальных медиафайлов. Импортировано **22 562 из 22 562 HTML-страниц, 26 744 размещения изображений и 153 раздела**. В базе нет машинных SEA/ZOOM-заголовков, повторяющихся ID блоков, отсутствующих изображений или битых путей к страницам. Кнопки старого viewer и печатные дубли исключаются; служебные/печатные HTML-представления сохраняются для переходов, но не попадают в пользовательскую выдачу и FTS.

Диагностика содержит только ссылки на отсутствующие в самих исходниках целевые якоря. Они не ломают переход: приложение открывает соответствующую статью с начала. Повреждённых HTML-страниц и непрочитанных изображений в финальном импорте нет.

## Известные ограничения и дальнейшая работа

Некоторые старые VML-схемы состоят из исходного PNG и браузерных векторных аннотаций; растровый оригинал импортируется, но интерактивность VML не воспроизводится. Применимость извлекается из DGC/model XML и текста, поэтому её можно дополнительно уточнить заводским сопоставлением VIN/комплектаций. Для следующих версий полезны расширенные XCUITest-сценарии заметок, Undo и VoiceOver-аудит на реальном устройстве.
